# Triage labels

The engineering skills use five canonical triage roles. This table maps them to
the labels configured in this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | More information from the reporter is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a triage role, use the corresponding GitHub label in
this table.
