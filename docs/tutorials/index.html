Gemeinsame Vorbereitung

Arbeite im Repository-Root mit uv und einer unterstützten Python-Version. Der erste Aufruf richtet die benötigten Umgebungen aus den Projektmetadaten ein. tools/tutorial_workspace.py kopiert nur die verfassten Produktdateien in ein neues, von Git ignoriertes Übungsprodukt unter products/tutorial_…/. Vorhandene Übungsprodukte werden nicht überschrieben; die Referenzprodukte bleiben unverändert.

Verträge und Tests erzeugst du anschließend über den Compiler. Bearbeite nie generated/ oder die generierten Tests von Hand. Bei einer neuen Übungsrunde behalte dein vorhandenes Produkt und benutze einen separaten Checkout; es gibt keinen automatischen Reset.

1. SQL API: der vollständige Weg

Eine Shape lesen, kompilieren, die echte Schnittstelle prüfen, eine Datenbedingung verschärfen und die Implementierung nachziehen.

2. KfW: Decision und HTTP

Eine explizite Anfrage auswerten und den spezifizierten HTTP-Status ändern, ohne neue fachliche Felder zu erfinden.

3. Cloud: denselben Kern wiederverwenden

Regeln, Pflichten und Nachweisanforderungen unterscheiden und einen ausdrücklich beschriebenen Fragetext ändern.

Die Beispiele wählen konkrete Implementierungstechnologien. Diese Entscheidungen sind keine universellen Produktanforderungen. KfW und Cloud sind eng begrenzte Software-Testfälle, keine Beratung, Förderzusage, Zertifizierung oder Sicherheitsgarantie.
